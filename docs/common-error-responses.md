# Common error responses

> What each HTTP status and error code from the gateway means, and what to change before you retry.

The full page is on the TopxAI site: https://ai.topxea.com/docs/common-error-responses (in Chinese: https://ai.topxea.com/docs/common-error-responses?lang=zh).

It covers:

- 401 authentication_error
- 403 permission_denied
- 402 insufficient_quota
- 429 rate_limited
- 400 invalid_request
- 404 and 5xx
- stream_interrupted
- An error partway through an answer

All documentation: [README](../README.md#documentation) · https://ai.topxea.com/docs
