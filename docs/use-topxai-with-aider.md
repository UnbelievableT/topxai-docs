# Aider with TopxAI: OPENAI_API_BASE and the model name

> Run aider against TopxAI with OPENAI_API_BASE=https://ai.topxea.com/v1 and --model openai/claude-sonnet-5-5, or the Anthropic variables for the Claude line.

The full page is on the TopxAI site: https://ai.topxea.com/docs/use-topxai-with-aider (in Chinese: https://ai.topxea.com/docs/use-topxai-with-aider?lang=zh).

It covers:

- OpenAI-compatible (every text model)
- Anthropic (Claude, with prompt caching)
- Model metadata
- Persisting it
- If it fails

All documentation: [README](../README.md#documentation) · https://ai.topxea.com/docs
