# Cline and Roo Code with TopxAI: the OpenAI-compatible provider

> Set the provider to OpenAI Compatible with base URL https://api.topxai.xyz/v1, a TopxAI key and a model id; or the Anthropic provider with a custom base URL.

The full page is on the TopxAI site: https://api.topxai.xyz/docs/use-topxai-with-cline-and-roo-code (in Chinese: https://api.topxai.xyz/docs/use-topxai-with-cline-and-roo-code?lang=zh).

It covers:

- OpenAI Compatible
- Anthropic with a custom base URL
- Agent mode and cost
- If it fails
