# LangChain with TopxAI: ChatOpenAI and ChatAnthropic with a base URL

> Use TopxAI from LangChain (Python and JavaScript) by passing base_url to ChatOpenAI for every text model, or to ChatAnthropic for Claude with prompt caching.

The full page is on the TopxAI site: https://ai.topxea.com/docs/use-topxai-with-langchain (in Chinese: https://ai.topxea.com/docs/use-topxai-with-langchain?lang=zh).

It covers:

- Python
- JavaScript
- Environment variables
- Embeddings
- If it fails

All documentation: [README](../README.md#documentation) · https://ai.topxea.com/docs
