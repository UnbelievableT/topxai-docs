# llm CLI with TopxAI: extra-openai-models.yaml

> Register TopxAI models in llm’s extra-openai-models.yaml with api_base https://api.topxai.xyz/v1, store the key with llm keys set, and prompt from the shell.

The full page is on the TopxAI site: https://api.topxai.xyz/docs/use-topxai-with-llm-cli (in Chinese: https://api.topxai.xyz/docs/use-topxai-with-llm-cli?lang=zh).

It covers:

- Register the models
- Prompt
- Responses API
- If it fails

All documentation: [README](../README.md#documentation) · https://api.topxai.xyz/docs
