# LobeChat with TopxAI: the OpenAI proxy address

> Set OpenAI’s API proxy address to https://ai.topxea.com/v1 in LobeChat, or OPENAI_PROXY_URL for a deployment, and fetch the model list.

The full page is on the TopxAI site: https://ai.topxea.com/docs/use-topxai-with-lobechat (in Chinese: https://ai.topxea.com/docs/use-topxai-with-lobechat?lang=zh).

It covers:

- In the app
- Self-hosted, with variables
- Images
- If it fails

All documentation: [README](../README.md#documentation) · https://ai.topxea.com/docs
