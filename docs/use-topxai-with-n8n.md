# n8n with TopxAI: an OpenAI credential with a base URL

> Create an OpenAI credential in n8n with base URL https://api.topxai.xyz/v1 and a TopxAI key, then use any catalogue model in the Chat Model and AI Agent nodes.

The full page is on the TopxAI site: https://api.topxai.xyz/docs/use-topxai-with-n8n (in Chinese: https://api.topxai.xyz/docs/use-topxai-with-n8n?lang=zh).

It covers:

- Credential
- Nodes
- Notes
- If it fails
