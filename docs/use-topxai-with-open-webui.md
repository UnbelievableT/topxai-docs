# Open WebUI with TopxAI: one OpenAI connection, every model

> Add https://api.topxai.xyz/v1 as an OpenAI API connection in Open WebUI; the model list fills from /v1/models and every text model is ready to chat.

The full page is on the TopxAI site: https://api.topxai.xyz/docs/use-topxai-with-open-webui (in Chinese: https://api.topxai.xyz/docs/use-topxai-with-open-webui?lang=zh).

It covers:

- In the admin panel
- With environment variables
- What is listed
- Images
- If it fails

All documentation: [README](../README.md#documentation) · https://api.topxai.xyz/docs
