# Vercel AI SDK with TopxAI: createOpenAI, createAnthropic and openai-compatible

> Create an AI SDK provider with baseURL https://ai.topxea.com/v1 and a TopxAI key, then use generateText or streamText with any catalogue model.

The full page is on the TopxAI site: https://ai.topxea.com/docs/use-topxai-with-vercel-ai-sdk (in Chinese: https://ai.topxea.com/docs/use-topxai-with-vercel-ai-sdk?lang=zh).

It covers:

- @ai-sdk/openai
- @ai-sdk/anthropic
- @ai-sdk/openai-compatible
- Notes
- If it fails

All documentation: [README](../README.md#documentation) · https://ai.topxea.com/docs
